# To-Do List App

A simple, user-friendly To-Do List app built using HTML, CSS, and JavaScript. This project uses the browser's local storage to save tasks so that they persist even after the page is refreshed.

## Features
- Add new tasks.
- Mark tasks as completed.
- Delete tasks.
- Tasks are stored in the browser's local storage.

## Technologies Used
- **HTML**: Structure of the app.
- **CSS**: Styling for the app.
- **JavaScript**: Adding interactivity and local storage functionality.

## How to Use
1. Open the app in any modern web browser by running the `index.html` file.
2. Use the input field to type in a new task and click **Add**.
3. Click on a task to mark it as completed or uncompleted.
4. Click the **Delete** button next to a task to remove it.
